How one final completion target is attributed across native layers

Frozen V-JEPA is evaluated with one fixed target: the negative L1 score on the hidden target tokens. Switch between the 12 predictor blocks and the 24 encoder blocks to inspect where the same score receives positive attribution.

Each layer is normalized independently over its eight time bins, so brightness is a spatial distribution within a layer, not a cross-layer importance score. Gray cells are hidden target tokens. Predictor maps show visible-key attention-branch attribution; encoder maps show visible-token attribution from all encoder queries.
